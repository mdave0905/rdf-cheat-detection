Reconciliation Divergence Fingerprinting

In multiplayer games, the server checks player movement by running its own calculation for every input. If the player's claimed position doesn't match the server's result, a divergence occurs. This research proves that movement cheats produce unmistakable error patterns that bad Wi-Fi cannot mimic, allowing servers to catch cheaters with 99.4% accuracy without invasive client-side software.

1. Honest Player Baseline RQ1

Key Takeaway: Ping/latency alone causes 0.00 m desync for honest players. Desync only occurs when packets are lost in transit, and even then, the average error stays tiny (≤ 0.40 m) and heals quickly.

Because honest players run the exact same movement logic as the server, both sides calculate identical positions. When packets drop, the server misses a single step, creating a small, temporary error plateau until the client snaps back.
